# Design System AB Data

Репозиторий общих данных дизайн-системы.

- `JSONS` — private source каталогов компонентов, токенов, стилей и indexes для Apollo. Публичная read-only копия публикуется через `Ackedze/apollo` GitHub Pages.
- `redpol` — материалы редакционной политики.
- `apollo-stats` — локальные JSON-отчёты проверок Apollo. В MVP отчёты сохраняет `services/apollo-stats-collector`; автоматическая публикация в Git не выполняется.
