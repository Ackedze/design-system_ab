## 1. Назначение паттерна

Паттерн описывает правила использования компонента Amount для отображения денежных сумм и других числовых данных с размерностью в интерфейсах.

Паттерн фиксирует:

- структуру компонента;
- правила настройки частей суммы;
- требования к типографике, цвету и знакам;
- правила использования Amount в таблицах, табличных списках, steps, TableBulkActions, input и сайд-панели;
- ограничения по opacity, начертанию и дублированию валюты.

---

## 2. Структура компонента

Компонент Amount состоит из обязательной и опциональных частей.

| Часть | Название | Обязательность | Описание |
|---|---|---|---|
| 1 | Major | Обязательная | Основная целая часть суммы |
| 2 | Minor | Опциональная | Дробная часть суммы |
| 3 | Currency | Опциональная | Валюта |
| 4 | Addon | Опциональная | Контейнер для дополнительного элемента |

Пример структуры:

```text
1 234 567,00 ₽
| |       |  |
1 2       3  4
```

---

## 3. Как пользоваться компонентом дизайнеру

### 3.1. Minor, Currency и Addon

Minor, Currency и Addon включаются через пропсы.

Addon вставляется через замену слота.

Высота аддона должна соответствовать высоте строки Major-части.

Если нужен аддон под конкретную высоту строки, его нужно подготовить отдельно.

В вёрстке Addon работает как слот, который может принять любой компонент.

---

### 3.2. Кегль, вес и цвет

Стиль типографики и цвет текста изменяются через настройку текстовых слоёв.

В вёрстке компонент наследует стиль родителя.

При необходимости можно переопределить:

- вес Major-части;
- вес всех частей сразу на `bold`, чтобы сделать сумму более акцентной.

---

### 3.3. Minor-часть

Не используем настройку:

```text
minor :: opacity :: true
```

Для акцента можно изменить вес Minor-части на `regular`.

---

### 3.4. Пробелы между разрядами

Для отступов между разрядами чисел используется математический пробел.

```text
1 234 567,00 ₽
```

Не заменяй математический пробел обычным пробелом.

---

### 3.5. Математические знаки

Для отрицательных значений используется математический минус, а не тире.

```text
−1 234 567,00 ₽
```

Не используем:

```text
-1 234 567,00 ₽
–1 234 567,00 ₽
—1 234 567,00 ₽
```

---

### 3.6. Цвет

Цвет `text/positive` используется для пополнений только в таблицах и табличных списках.

Во всех остальных случаях используется только `text/primary`.

```text
+1 234 567,00 ₽ → text/positive только в таблицах и табличных списках
−1 234 567,00 ₽ → text/primary
```

---

## 4. Amount с заголовочными стилями

При использовании крупных заголовочных стилей не используем Opacity.

Затрагивает стили:

- `Headline-System`;
- `Headline-System-Mobile`.

**Не ок**

```text
Minor или Currency отображаются через opacity
```

**Ок**

```text
Minor и Currency отображаются без opacity
```

---

## 5. Amount в Table и Table KIB

### 5.1. Opacity

В таблицах для Minor-части и Currency не используется Opacity.

```text
minor :: opacity :: true → не использовать
currency :: opacity :: true → не использовать
```

---

### 5.2. Начертание

Для отображения второстепенных значений с числовыми данными с размерностью используется начертание `Regular`.

Для основной суммы используется `Medium`.

| Тип значения | Начертание |
|---|---|
| Основная сумма | Medium |
| Второстепенное значение | Regular |

В обычной таблице не используем `Regular` для отображения основной суммы.

---

### 5.3. Валюта в заголовке колонки

Если валюта указана в названии колонки, не дублируем её в значениях сумм.

Условие: все суммы в колонке должны быть в одной валюте.

**Не ок**

```text
Сумма, ₽
210 000,06 ₽
25 000,26 ₽
16 000,00 ₽
```

**Ок**

```text
Сумма, ₽
210 000,06
25 000,26
16 000,00
```

---

### 5.4. Цвет для пополнений и списаний

Не используем один цвет, если в колонке основной суммы есть знаки `+` и `−`.

Для пополнений лучше использовать `text/positive`.

Для списаний лучше использовать `text/primary`.

Не используем красный цвет для суммы списания со знаком `−`.

```text
+305,00 ₽ → text/positive
−100,00 ₽ → text/primary
```

---

### 5.5. Несколько колонок с пополнением

Если в таблице несколько колонок с данными со знаком `+`, не окрашиваем все значения в `text/positive`.

Достаточно использовать цвет для колонки с основной суммой.

Если в колонке суммы два значения, окрашиваем в `text/positive` только основное значение со знаком `+`.

---

### 5.6. Выравнивание

Числовые данные с размерностью всегда выравниваются по правому краю.

```text
Amount → align right
```

---

### 5.7. Типографика в расширенной таблице

Типографика Amount должна совпадать с колонкой суммы в расширенной таблице.

---

## 6. Amount в табличных списках

### 6.1. Opacity

В заголовках и параграфах табличных списков не используем Opacity.

---

### 6.2. Жирность значений

Не используем Opacity и одинаковую жирность для значений Amount.

Для общей суммы лучше использовать `Bold`.

Для остальных значений лучше использовать `Medium`.

| Тип значения | Начертание |
|---|---|
| Общая сумма | Bold |
| Остальные суммы | Medium |

---

### 6.3. Цвет

Для пополнений в табличных списках можно использовать `text/positive`.

Для списаний используется `text/primary`.

---

## 7. Amount в steps

Для отображения значений с числовыми данными с размерностью в steps:

- не используем Opacity для Minor-части;
- не используем любое другое начертание, кроме `Regular`.

```text
Amount в steps → Regular
Minor opacity → false
```

---

## 8. Amount в TableBulkActions

Для отображения пополнений и списаний в TableBulkActions:

- не используем знаки `+` и `−`;
- используем только цвет `text/primary`;
- для Minor-части не используем Opacity.

**Не ок**

```text
+1 234 567,00 ₽
−1 234 567,00 ₽
```

**Ок**

```text
1 234 567,00 ₽
1 234 567,00 ₽
```

---

## 9. Amount в input

Для Minor-части в input не используем Opacity.

```text
minor :: opacity :: true → не использовать
```

---

## 10. Amount в сайд-панели

Формат и цвет суммы в сайд-панели повторяют то, что пользователь видит на странице.

### 10.1. Поступления и списания

Если в таблице есть поступления и списания, в сайд-панели используется сумма соответствующего цвета и знак.

```text
−1 234 567,00 ₽ → списание
+1 234 567,00 ₽ → поступление
```

### 10.2. Баланс или остаток

Если в таблице данные отображают баланс или остаток, в сайд-панели сумма отображается без знака операции.

```text
3 458 000,00 ₽
```

## 12. Сжатая версия для RAG

Компонент Amount используется для отображения сумм и числовых данных с размерностью. Обязательная часть компонента — Major, то есть основная целая часть суммы. Minor, Currency и Addon опциональны и включаются через пропсы; Addon вставляется через слот и должен соответствовать высоте строки Major. Для Minor-части не используется opacity. В крупных заголовочных стилях Headline-System и Headline-System-Mobile также не используется Opacity. Между разрядами чисел используется математический пробел, а для отрицательных значений — математический минус, не тире. Цвет text/positive применяется для пополнений только в таблицах и табличных списках; в остальных случаях используется text/primary. Для списаний не используется красный цвет. В таблицах Amount выравнивается по правому краю. Основная сумма в таблице набирается Medium, второстепенные значения — Regular. Если валюта указана в заголовке колонки и все значения в одной валюте, валюту не дублируют в ячейках. Если в колонке два значения, text/positive применяется только к основному значению со знаком плюс. В табличных списках не используют Opacity и одинаковую жирность для Amount: общая сумма — Bold, остальные — Medium. В steps Amount отображается Regular и без opacity для Minor. В TableBulkActions для пополнений и списаний не используют знаки плюс и минус, применяют только text/primary и не используют opacity для Minor. В input для Minor также не используют opacity. В сайд-панели формат и цвет суммы повторяют то, что пользователь видит на странице: для поступлений и списаний сохраняются знак и цвет, для баланса или остатка сумма отображается без знака операции.
