# Divider — Mobile Web

Используется общий [Divider.figma.ts](../../code-connect/Divider.figma.ts)
и `Divider` из `arui-private/divider`. Figma Divider также универсальный:
один set с Presets=default/light, применимый к Desktop и Mobile Web.

Default использует библиотечный цвет. Light требует реального app className
по [CSS-рецепту](../../code-connect/Divider.example.css). Ширину и отступы
задаёт родительская композиция. [Проверки и ограничения](../../code-connect/README.md).
