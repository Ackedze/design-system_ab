сохранять свежие отчёты. Старые captures не содержат text.decoration.
Использовать копии чистых экземпляров; новые узлы на холсте этим этапом не создавались.

| AS-D01 | Чистые Paragraph, D Headline, M Headline | Нет нарушений и unknown оформления |
| AS-D02 | Подчеркнуть Major целиком | Нарушение TEXT decoration |
| AS-D03 | Если Figma позволяет, подчеркнуть только выделенный диапазон Major | Нарушение; иначе отметить недоступный UI-сценарий |
| AS-D04 | Подчеркнуть/зачеркнуть Minor, Currency или знак Operation | Нарушение соответствующей TEXT-роли |
| AS-D05 | Добавить фон корню; отдельно контейнеру Major/Minor/Currency | Нарушение background |
| AS-D06 | Добавить тень/blur корню либо TEXT; изменить радиус эффекта | Нарушение effectDetailsV1 |
| AS-D07 | Сбросить изменения D02–D06 | Нарушения исчезают |
| AS-D08 | Штатно сменить Style/Negative; выключить Operation | Нет ложных нарушений оформления |
| AS-D09 | Всем видимым текстовым частям назначить один разрешённый библиотечный токен | Оформление не запрещает смену цвета; binding rules сохраняются |
| AS-D10 | Разрешённый IconView/StatusBadge в Addon с собственным оформлением | Нет сравнения с placeholder; семейство/высота проверяются отдельно |

В отчёте должны быть manualRevision=9 и Editor 0.2.64. Само правило остаётся Draft
до приёмки; проверка в Editor исполняет его как authoring preview.

## Архив приёмки: r5 / Editor 0.2.62 — вложенный Addon

Перезапустить Editor, импортировать свежий `editor/AmountStyles.editor-input.zip`.
Выбирать корень AmountStyles, а не вложенный Amount или IconView.

1. Повторить [AS-B08c / 13161:65182](https://www.figma.com/design/I3MsagXR8Tz2eZcGtIgUk8/?node-id=13161-65182).
   Сохранённый IconView 16 с собственным цветом: обе проверки Addon проходят,
   три текстовые проверки проходят. Прежних двух human-review больше нет.
2. На копии заменить Addon на библиотечный компонент другого семейства (например
   Button): INSTANCE проходит, ограничение IconView/StatusBadge даёт нарушение.
   Не менять цвет или стиль текстовых частей AmountStyles.
3. У такой копии штатно выключить Addon через свойство вложенного Core Amount:
   правило семейства неприменимо, нарушение скрытого Addon не показывается.

Это план, новые узлы в Figma в рамках r5 не создавались. Высота Addon ещё не
проверяется (отдельный P0), шесть context-only правил оставляют общий итог неполным.
Недоступная identity/неоднозначный слот — автоматические защитные тесты, не ручные кейсы.

## Ближайшая приёмка r2 — текстовые привязки

На каждом кейсе скачать JSON отчёт. Проверять именно три правила привязок:
общая проверка пока остаётся неполной из-за шести других P0.

| Кейс | Изменение | Ожидается |
|---|---|---|
| AS-B01 | Штатные Paragraph, D Headline и M Headline; переключение Style | Три проверки привязок проходят |
| AS-B02 | Все видимые текстовые части перекрасить одним другим токеном | Разрешено; Addon не требуется перекрашивать |
| AS-B03 | У одной части выбрать другой токен, в том числе с тем же RGB | parts-share-color: нарушение |
| AS-B04 | Отвязать fill token одной текстовой части | parts-share-color: нарушение независимо от визуального совпадения |
| AS-B05 | Назначить другой Text Style одной части | Нарушение общего стиля и выбранного style baseline |
| AS-B06 | Назначить всем частям один одинаковый, но неверный Text Style | Равенство проходит; выбранный style baseline нарушен |
| AS-B07 | Детач Text Style одной части без ручного изменения кегля | Обнаружена потеря привязки |
| AS-B08 | Скрыть изменённую Minor/Currency через штатную настройку; отдельно изменить цвет Addon | Эти изменения не нарушают три проверки видимых текстовых частей |

Пустой Custom-текст допустим, но Text Style и fill binding у его слоя сохраняются.
Искусственные проверки mixed ranges и недоступных ключей остаются автоматическими;
от дизайнера не требуется воспроизводить недоступные в UI операции.

## r3 / Editor 0.2.60 — повторная проверка Operation и Opacity

Перезапустить Editor, импортировать `editor/AmountStyles.editor-input.zip` r3.

1. Существующий instance `13163:61026`, Operation=False: fixed-part-order проходит.
   Включить Operation: это же правило продолжает проходить.
2. Существующий instance `13164:61060`, Minor/Currency Opacity=True:
   оба свойства запрещены; фактические 60% вместо 100% также определяются.
   Отдельное нарушение Text Style Major сохранится, пока его привязка не восстановлена.
3. В этом экземпляре вернуть обоим Opacity=False без ручной прозрачности:
   четыре opacity-нарушения должны исчезнуть. Само отсутствие Operation допустимо.
4. Шесть context-only правил сохраняют Draft/неполную проверку. Unknown после
   variant changes — отдельный незакрытый пункт, не ожидаемый pass.

Перестановка/повреждённая структура проверяются автоматическими runtime-тестами;
это не утверждение, что перестановка доступна дизайнеру внутри Figma instance.
