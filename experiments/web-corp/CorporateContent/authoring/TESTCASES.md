## Grid/clipping · Editor 0.2.67 · принято

Это тестовый план для двух существующих требований из
[`RULE-OWNERSHIP.md`](RULE-OWNERSHIP.md): grid-style-protected и
clips-content-disabled. Эти правила созданы вручную и приняты;
сам захват новых фактов не добавляет их в контракт.

1. Импортировать `corporate-content.component-contract.zip` (manual r8),
   открыть живой preview и выбрать root `[D] CorporateContent`.
2. Проверить существующее отдельное правило для свойства слоя **Стиль сетки**
   (`layout.gridStyleId`): область «Только выбранный слой», запрет ручного
   изменения, сравнение с независимым library baseline.
3. Проверить существующее отдельное правило для **Обрезать содержимое**
   (`layout.clipsContent`): та же область и сравнение с library baseline.
   До reviewed проверить, что baseline библиотеки равен `false`.
4. При изменении правил заполнить rationale и экспортировать новый ZIP.
   У группового `auto-layout@1` состав свойств остался прежним.

| Кейс | Действие | Ожидание новых двух проверок |
|---|---|---|
| CC-GC01 | Чистый экземпляр библиотеки | Оба правила пройдены |
| CC-GC02 | Снять grid style с root | Только grid rule нарушен |
| CC-GC03 | Восстановить grid style и включить clips content | Только clipping rule нарушен |
| CC-GC04 | Восстановить оба свойства | Оба правила снова пройдены |

Для каждого кейса скачать отчёт проверки. При наличии «Не выполнено» приёмка
остаётся открытой; старые отчёты без этих фактов для этой проверки не подходят.
Существующие правила fill/layout должны сохранять свои результаты.

BackgroundPlate Color и Body slot проверяются отдельными кейсами после
подтверждения их фактов и границ владения.
