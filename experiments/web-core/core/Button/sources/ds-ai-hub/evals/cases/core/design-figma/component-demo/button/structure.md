## Секции

### Platform

Покажи desktop и mobile друг под другом.

- Подпись «ButtonDesktop · Secondary · 56» — вторичная desktop-кнопка высотой 56 с текстом «Кнопка»
- Подпись «ButtonMobile · Secondary · 56» — вторичная mobile-кнопка высотой 56 с текстом «Кнопка»

### View

- Без подписи — все доступные виды кнопки высотой 56

### View · Disabled

- Без подписи — те же виды в недоступном состоянии

### View · Loading

В loading-состоянии покажи штатный Spinner; его палитра и поведение — по знаниям компонента.

- Без подписи — те же виды во время загрузки

### View · Inverted

Тёмная подложка секции.

- Без подписи — те же виды в инвертированной палитре

### Size — Desktop

- Без подписи — вся шкала размеров desktop-кнопки

### Size — Mobile

- Без подписи — вся шкала размеров mobile-кнопки

### Shape

- Без подписи — все доступные формы кнопки

### Addons

- Подпись «leftAddons» — текст «Кнопка» и иконка слева
- Подпись «rightAddons» — текст «Кнопка» и иконка справа
- Подпись «left + right» — текст «Кнопка» и иконки с обеих сторон
- Подпись «SingleIcon (icon only)» — только иконка, без видимого текста

### Hint

- Без подписи — размеры 72, 64 и 56 от большего к меньшему; основной текст «Кнопка», дополнительный — «Подсказка»

### Layout

Покажи варианты ширины друг под другом.

- Подпись «Мин.» — минимальная ширина с текстом «Ок»
- Подпись «Ширина зависит от лейбла» — длинный текст
- Подпись «Ширина задана вручную» — фиксированная ширина
- Подпись «Занимает всю ширину контейнера» — на всю ширину родителя

### Поведение лейбла · Hug

Покажи кнопку с дополнительным текстом и обеими иконками в достаточно широкой области; высота
области зависит от содержимого.

- Подпись «hug» — текст занимает только необходимую ширину

### Поведение лейбла · Fill

Покажи тот же состав, но текстовый блок растягивается на свободное место. Кнопка вторичная,
основной и дополнительный тексты выровнены по центру.

- Подпись «fill» — текстовый блок занимает доступную ширину

### Перенос текста · nowrap

- Подпись «nowrap» — длинный лейбл без переноса

### Перенос текста · перенос

- Подпись «перенос» — длинный текст переносится внутри кнопки фиксированной ширины

### Размытие фона · включено

На контрастном цветном градиенте покажи рядом две центрированные инвертированные вторичные
кнопки: сначала недоступную, затем обычную. Размытие фона включено.

- Подпись «blur on» — фон под кнопками размывается

### Размытие фона · выключено

Та же сцена, фон и те же две кнопки.

- Подпись «blur off» — фон под кнопками остаётся резким
