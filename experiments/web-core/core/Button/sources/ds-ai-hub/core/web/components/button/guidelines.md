# Button

Основной тип кнопки для большинства действий на экране.

Смежные компоненты: [`IconButton`](../icon-button/guidelines.md), [`PickerButton`](../picker-button/guidelines.md), [`Link`](../link/guidelines.md). Общие паттерны групп кнопок — `core/common/patterns/buttons.md`.

## Когда использовать

- Действие, которое пользователь может выполнить на экране.
- Нужна заметная иерархия: главное действие vs дополнительные.

## Основные правила

- Рекомендуемый размер для мобильных и десктопных веб-продуктов — `56px`.
- View по приоритету: `accent`, `primary`, `secondary`, `outlined`, `transparent`, `text`.
- `text` отличается от `transparent` отсутствием кликабельной области вокруг текста. Используй `text` для низкоприоритетного **действия**.
- `Button` с `view="text"` — это кнопка, не компонент `Link`. Для переходов — [`Link`](../link/guidelines.md).

## CustomButton

Используй, если стандартных view `Button` недостаточно (особый цвет, градиент, промо-визуал). Не ради мелкого отличия, которое закрывает стандартная `Button`.

## Приоритет и сочетаемость

Приоритет = заметность view: `accent`/`primary` → `secondary` → `outlined` → `transparent` → `text`.

- Не больше трёх кнопок рядом; лишнее — в [`PickerButton`](../picker-button/guidelines.md) или другое место.
- Не ставь рядом две высокоприоритетные (`accent` и `primary`).
- Одна главная, остальные дополнительные.

## Лейаут

- Вертикальный лейаут безопаснее для длинных лейблов и локализации.
- Мобильный: при горизонтали главная справа; при вертикали — сверху.
- Десктоп: под формами/в модалках при горизонтали — по левому краю, главная первой; «Назад» → «Вперёд» в логическом порядке.

## Фиксирование блока кнопок

Фиксируй только если кнопка — целевое действие **и** контент под скроллом не обязателен до нажатия. Иначе не фиксируй.

Мобильный футер: только пара кнопок. Десктоп: можно несколько кнопок и умеренный доп. контент.

## Алгоритм

1. Главное и дополнительные действия.
2. Тип: Button / CustomButton / [`PickerButton`](../picker-button/guidelines.md) / [`IconButton`](../icon-button/guidelines.md) / [`Link`](../link/guidelines.md).
3. View по приоритету; не больше трёх рядом; сочетаемость.
4. Лейаут с учётом устройства и длины лейблов.
5. Фиксирование — только по правилам выше.
