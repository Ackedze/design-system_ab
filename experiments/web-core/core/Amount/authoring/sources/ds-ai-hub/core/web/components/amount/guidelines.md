# Amount

Отображение отформатированной денежной суммы: целая и дробная части, валюта, опциональный слот справа.

Смежные компоненты: [`AmountInput`](../amount-input/guidelines.md). Редполитика чисел и валют — `core/common/editorial-policy/numbers-and-amounts.md`, `core/common/editorial-policy/currencies.md`. Компонент отвечает за визуальное форматирование в UI; текст в абзацах правь по редполитике отдельно.

## Когда использовать

- Баланс, цена, сумма операции, лимит, кэшбэк — в интерфейсе, где нужен единый паттерн суммы.
- В составе строки (`PureCell`, карточка, таблица) — инстанс `Amount` в Figma или `<Amount />` в коде.
- Положительное изменение с «+» — `showPlus`.
- Нулевые копейки в макете не показывают — `view` по умолчанию (`default`); нули нужны — `view="withZeroMinorPart"`.

## Когда не использовать

- Поле ввода суммы → [`AmountInput`](../amount-input/guidelines.md).
- Сумма внутри связного текста без UI-паттерна суммы → редполитика + обычный `Typography.Text`.

## Основные правила

- Макет с инстансом `Amount` → в коде `<Amount />`. Не заменяй ручной вёрсткой (отдельные `span` с цифрами, копейками и `₽`).
- `value` — число в минорных единицах (для рублей с `minority={100}`: `123456700` = 1 234 567,00 ₽).
- `minority` — обязателен; для рублей обычно `100`.
- `currency` — ISO-код (`RUB`, `USD`, …); символ или буквы — через `codeFormat`.
- Типографика наследуется от родителя: оберни в `Typography.Text` с нужным `view` и `weight` (`regular`, `medium`, `bold`). Без `fontWeight` на `Amount` мажорная часть по умолчанию bold; чтобы наследовать вес с родителя — см. `code/adapter.md`.
- Приглушить минорную часть и валюту — `transparentMinor` (в Figma — `Opacity=True` на `Minor` / `Currency`).
- Слот справа — `rightAddons` (в Figma — слой `Addon`).

## Алгоритм

1. Отображение или ввод? Ввод → [`AmountInput`](../amount-input/guidelines.md).
2. UI-паттерн суммы или текст в абзаце? Абзац → редполитика + `Typography.Text`.
3. Валюта, `minority`, нужны ли нулевые копейки и «+».
4. Типографика строки — с родителя; приглушение минорной части — по макету.
