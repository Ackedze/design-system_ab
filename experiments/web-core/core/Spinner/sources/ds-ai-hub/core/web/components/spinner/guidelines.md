# Spinner

Индикатор загрузки (лист / слот в других компонентах).

## Когда использовать

- Нужно показать ожидание (загрузка данных, обработка действия).
- Часто вложен в `Button` / другие компоненты как loading-состояние — см. адаптеры родителя и [`Button`](../button/guidelines.md).

## Основные правила

- Не заменяй контент бесконечным спиннером без возможности отмены/ошибки в сценарии.
- Размеры и варианты — `adapter.figma.md` / `adapter.code.md` этого компонента.
- Скелетон экрана/блока — [`Skeleton`](../skeleton/guidelines.md), не Spinner.
