# PaymentMaskedNumber r3 · Draft для проверки обновления

r3 подготовлен для ручного Git → Proxy → Apollo теста. В сообщение ошибки маски
добавлен маркер `[PMN r3 · проверка обновления]`; нормы r2 сохранены. Push и
установка оставлены владельцу: [порядок проверки](reports/manual-git-update-r3-2026-10-22/README.ru.md).

Один public root для desktop/mobile-web и его общего представления `universal`.
В r2 исправлена только область применения четырёх правил: r1 ошибочно пропускал
все проверки снимков `universal`. Нормы, bindings, эталоны и движок сохранены.

Повторный расчёт восьми снимков владельца: **0 / 0 / 1 / 1 / 0 / 1 / 1 / 1**.
Проверяются общий цвет Major/Minor, типографическая пара, точный литерал маски,
отступ Addon **6 px** и его высота относительно line-height номера.

Проверка формата открытого Major/Minor остаётся согласованным пробелом Draft.
При скрытом Addon runtime также сохраняет предупреждение о неполноте его
selector-проверок; оно не означает нарушение геометрии. Полный Ready не заявлен.

Evidence и воспроизводимый replay: `reports/skill-evals/platform-scope-r2-2026-10-21`.
Предыдущие r1 ZIP и receipts сохранены как исторические.
