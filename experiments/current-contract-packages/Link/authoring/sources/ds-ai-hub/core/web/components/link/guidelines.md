# Ссылки (Link)

Гайд помогает выбрать тип ссылки, способ подчёркивания и размер. Текст ссылки — `core/common/editorial-policy/`. Кнопки и CTA — `../button/guidelines.md`.

## Основные правила

- Используй `Link` для перехода или вспомогательного действия с текстовым акцентом, а не для главного CTA экрана.
- Ссылка наследует размер и начертание от родительской типографики — оборачивай в `Typography.Text` с нужным `view`.
- Подчёркивание — основной способ показать кликабельность; без него ссылку отличить от текста сложно.
- Не заменяй основное действие ссылкой в попапе или на странице — для этого `Button`.

## Типы ссылки

### Обычная ссылка

Переход на страницу внутри системы или на внешний ресурс.

- Основная индикация — сплошное подчёркивание (`underline={true}`, `pseudo={false}`).
- Передавай `href`; для внешних ресурсов — `target="_blank"` и `rel="noopener"`.
- Классическая синяя ссылка — `view="default"`.

### Псевдоссылка

Действие без перехода: раскрывает collapse, dropdown, popup.

- Используй `pseudo={true}` — в коде рендерится как `button`, не `<a>`.
- Индикация — пунктирное подчёркивание.

### Ссылка без подчёркивания

Допустима только как декоративный приём **вне** блока текста и только с `view="default"`.

- Не используй, если цвет — единственное отличие от обычного текста: это проблема доступности.
- В коде: `underline={false}`.

## View

Цвет ссылки. Не путать с `view` у `Typography.Text` — это разные props.

| `Link` `view` | Цвет |
|---|---|
| `default` | синяя ссылка (link-color) |
| `primary` | цвет основного текста (`text-primary`) |
| `secondary` | цвет второстепенного текста (`text-secondary`) |

Default в API компонента — `view="primary"`. Для классической синей ссылки задавай `view="default"` явно.

| Сценарий | `view` |
|---|---|
| отдельная синяя ссылка, навигация | `default` |
| ссылка внутри абзаца, в тон основному тексту | `primary` |
| второстепенная ссылка, подпись, мета | `secondary` |

## Размер

`Link` **не имеет** prop размера — наследует стиль от родителя.

| Контекст | `Typography.Text` `view` |
|---|---|
| мелкий текст, подписи | `primary-small` (14/20) |
| основной текст | `primary-medium` (16/24) |
| крупный текст | `primary-large` (18/24) |

В Figma размер задаётся variant `Size` на инстансе `Link`; в коде — обёрткой `Typography.Text`.

## Аддоны (иконки)

- Слоты `leftAddons` / `rightAddons` — для отдельной ссылки с иконкой.
- Высота иконки не должна превышать line-height текста ссылки.
- Если ссылка **встроена в текст** и без иконок — в Figma стилизуй текст (подчёркивание, цвет как у абзаца); в коде — `Link` с `view="primary"` внутри `Typography.Text`.

## Link vs Button

| Ситуация | Компонент |
|---|---|
| действие на экране (отправить, сохранить, подтвердить) | `Button` — `../button/guidelines.md` |
| переход, «вернуться к…», навигация | `Link` |
| действие без перехода (раскрыть collapse, dropdown) | `Link` с `pseudo={true}` |

## Формулировка текста

- Текст должен однозначно объяснять, куда ведёт ссылка.
- Недостаточно контекста: «Вернуться».
- Достаточно контекста: «Вернуться к настройкам».

Правила написания — `core/common/editorial-policy/`.

## Алгоритм выбора

1. Определи назначение: переход, псевдодействие или встроенная ссылка в тексте.
2. Если это действие на экране, а не переход — `Button`, не `Link`.
3. Выбери `view`: синяя ссылка — `default`; в тексте — `primary`; второстепенная — `secondary`.
4. Выбери подчёркивание: сплошное (переход), пунктир (`pseudo`), без подчёркивания — только вне текста и с `default`.
5. Задай размер через `Typography.Text`, не через prop `Link`.
6. Если нужны иконки — `leftAddons` / `rightAddons`; проверь высоту иконки.
7. Проверь текст ссылки по `core/common/editorial-policy/`.

При конфликте правил — `bridge.md`, затем `AGENTS.md`.

## Проверка перед ответом

1. Назови, переход это, псевдодействие или встроенная ссылка.
2. Проверь семантику: переход/навигация → `Link`; действие на экране → `Button`.
3. Проверь `view`: синяя — `default`, в тексте — `primary`, второстепенная — `secondary`.
4. Проверь подчёркивание и доступность.
5. Проверь размер: родительская типографика задана.
6. Проверь формулировку текста.
