# Сверка канала Proxy · 26.10.2026

Штатный установленный `data-release-cli.js check` получил из реального Git commit `da8d161a` совместимые runtime `ec9b3205` и data `aad90fa6`: exit 0, `updateAvailable=false`. Текущий пакет совпадает с состоянием после принятой локальной установки; установки, перезапуска и публикации в этом прогоне не было.

Прежний индекс с runtime `28075c51` отклонён существующим reader в отрицательном контроле. Проверка с подставленным индексом записана отдельно от настоящего сетевого CLI-запуска.

Причина красного индикатора — сохранённый отказ проверки при рассинхроне локального runtime и опубликованного Git index. Git уже обновлён внешним push. Проверка цвета после штатного пункта меню отложена владельцем; снятие красной точки пока не подтверждено.

Защита в навыке 0.1.8 применяется только при поручении поставки через Proxy: локальное совпадение файлов не заменяет actual remote check. Намеренно локальная, неопубликованная работа остаётся допустимой и явно получает `PENDING_PUBLICATION`; публикация автоматически не запускается. Совместимость прежних клиентов не выводится из успеха текущей установки.

При финальной сверке одна попытка завершилась `fetch failed`; ошибка сохранена, единственный повтор успешен. Причина сетевого сбоя не установлена, сетевой код не менялся.

Старый workspace entrypoint навыка 0.1.5 заменён короткой ссылкой на канонический навык 0.1.8. Старые bytes сохранены privately; supporting files не менялись.
