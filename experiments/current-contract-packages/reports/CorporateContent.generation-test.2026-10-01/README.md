# CorporateContent — тест генерации, 01.10.2026

[Стенд в Figma](https://www.figma.com/design/I3MsagXR8Tz2eZcGtIgUk8/?node-id=13251-13742)

Источник: актуальные ZIP-пакеты desktop r12 и mobile-web r7.

| Платформа | Сценарий | Результат | Baseline |
|---|---|---|---|
| Desktop | Пустой Body | 17/17 compliant | 2/2 |
| Desktop | Body с содержимым | 17/17 compliant | 2/2 |
| Mobile-web | Пустой Body | 17/17 compliant | 6/6 |
| Mobile-web | Body с содержимым | 17/17 compliant | 6/6 |

Всего: 68/68 проверок. Нарушений, неизвестных или невыполненных правил нет. Для каждого экземпляра независимо подтверждена одна граница native SLOT.

Профили `empty` использованы как задано: Body без дочерних элементов. Наполненные примеры используют те же представления и явное тестовое содержимое Body; его состав не внесён в контракт как обязательное требование. У всех четырёх сохранены библиотечные связи; SwapMe удалён, мобильные TopMargin и BottomMargin сохранены. Серый и белый page-фон выбраны явно для тестовых случаев.

Текст стенда и содержимого использует библиотечные стили, Alfa Interface Sans и привязки DS цвета. Стенд является отдельной матрицей примеров, а не полной продуктовой страницей.

Predicate Engine проверяет host и границу Body; содержимое открытого слота не объявлено проверенным этим контрактом. Для тестового содержимого отдельно проверены шрифт, стили, цветовые привязки и визуальная раскладка.

`captures.json` содержит факты экземпляров и независимых библиотечных эталонов. `evaluation.json` — результаты всех предикатов. `assembly-readback.json` — данные сборки и итогового чтения Figma. `report.json` — версии, хеши источников, область проверки и сводка.
