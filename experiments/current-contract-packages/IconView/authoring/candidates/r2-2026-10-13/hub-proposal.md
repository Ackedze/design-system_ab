# Предложение для Figma adapter IconView

Добавить раздел после описания публичного Text API. Применение к canonical Hub отложено до приёмки r2; эта запись не меняет текущие документы Hub.

## Типографика текста

- При включённом Text нужен библиотечный текстовый стиль из Web :: Typography.
- Разрешено выбирать другой библиотечный текстовый стиль. Размер, семейство шрифта, межстрочный интервал и трекинг определяются выбранным стилем.
- Отвязанный текстовый стиль и стиль вне библиотечного каталога запрещены.
- Цвет и обводка текста регулируются отдельно; разрешение смены текстового стиля не разрешает ручную смену paint.
- При выключенном Text эта проверка не применяется.
