## Section 1: Определение

Link — интерактивный текстовый элемент, который помогает перейти к внутреннему документу, странице, якорю, внешнему ресурсу, открыть информационный слой или запустить действие на странице.

В Альфа-Бизнесе ссылка должна быть визуально отличима от обычного текста и предсказуема по поведению. Пользователь должен понимать, куда приведёт ссылка или какое действие она запустит, ещё до наведения курсора.

Паттерн описывает правила для desktop. Для Mobile Web и мобильной адаптивной версии используется отдельный паттерн АБМ «Использование ссылок».

## Section 2: Когда использовать

Используйте Link, когда нужно:

- перейти к другой странице, разделу или якорю внутри продукта;
- открыть внутренний документ, справку или связанный материал;
- открыть внешний ресурс;
- открыть модальное окно, попап, дропдаун, коллапс или другой информационный слой;
- запустить действие на текущей странице, если по контексту это именно текстовое действие, а не кнопка.

## Section 3: Когда не использовать

Не используйте Link, когда:

- действие является основным или заметным CTA — для этого нужна кнопка;
- действие находится в карточке и должно считываться как стандартная операция с объектом — используйте `IconButton` или текстовую кнопку;
- ссылка размещается в острове или Plate как отдельный элемент — там заметнее и понятнее работают кнопки;
- ссылка не подчёркнута и отличается от текста только цветом;
- нужно показать ссылку в Mobile Web или мобильной адаптивной версии — используйте правила АБМ.

## Section 4: Принципы

1. Ссылка должна быть заметной без наведения курсора.
2. Текст ссылки должен объяснять, что произойдёт после клика.
3. Визуальный стиль ссылки зависит от контекста: обычный текст, карточка, legal-текст, Tooltip, Notification, Plate или остров.
4. Внешние переходы должны быть явно отличимы, если ссылка или кнопка стоят отдельно.
5. Дизайнер проверяет, что все ссылки ведут туда, куда обещают. Неработающие ссылки нарушают сценарий и снижают доверие.

## Section 5: Структура текста

Ссылка может быть одним словом или фразой. Выбирайте длину по смыслу:

- одно слово — если его достаточно, чтобы понять переход;
- фраза — если без контекста пользователь не поймёт, что откроется;
- полный адрес — если важно показать точный URL или по техническим причинам нельзя спрятать адрес за текстом.

Текст ссылки должен оставаться понятным, даже если убрать URL. Не используйте слова, которые не объясняют действие или цель перехода: «здесь», «тута», «документ», «файл», «ссылка», «сайт».

Если на экране несколько ссылок, группируйте их так, чтобы пользователь мог быстро просканировать список.

## Section 6: Правила

### Rule 1: Используйте ссылку только для поддержанных действий

- ruleId: rule:components.link.supported-actions
- severity: error
- appliesTo: component
- checkType: llm
- autofix: no

Link можно использовать для перехода на страницу, якорь, внутренний документ, внешний ресурс, открытия информационного слоя или запуска действия на текущей странице.

#### Правильно

```text
Ссылка открывает справку по тарифам.
```

#### Неправильно

```text
Ссылка используется как основной CTA формы.
```

#### Почему

Если действие главное или требует заметного призыва, пользователь ожидает кнопку, а не текстовую ссылку.

### Rule 2: Применяйте паттерн только на desktop

- ruleId: rule:components.link.desktop-only
- severity: warning
- appliesTo: screen
- checkType: deterministic
- autofix: no

Этот паттерн описывает ссылки для desktop. Для Mobile Web и мобильной адаптивной версии используйте паттерн АБМ «Использование ссылок».

#### Правильно

```text
Desktop-экран использует правила Link из этого паттерна.
```

#### Неправильно

```text
Mobile Web-экран использует desktop-правила Link.
```

#### Почему

На мобильных платформах отличаются размеры, поведение и правила взаимодействия со ссылками.

### Rule 3: Подчёркивайте обычные ссылки

- ruleId: rule:components.link.default-underline
- severity: error
- appliesTo: component
- checkType: deterministic
- autofix: partial

Обычная ссылка должна быть подчёркнута и иметь тот же размер текста, что и соседний текстовый блок.

#### Правильно

```text
В тексте есть синяя подчёркнутая ссылка того же размера, что и основной текст.
```

#### Неправильно

```text
Ссылка отличается только цветом.
```

#### Почему

Пользователь может не различать цвета. Подчёркивание помогает распознать кликабельный текст.

### Rule 4: Отделяйте псевдоссылку от обычной ссылки

- ruleId: rule:components.link.pseudo-link
- severity: error
- appliesTo: component
- checkType: llm
- autofix: no

Псевдоссылка открывает информационный слой или запускает действие на странице, но не переводит пользователя на другую страницу. В тексте она выделяется цветом и пунктирным подчёркиванием. Для разработки нужно явно указать, что это псевдоссылка.

#### Правильно

```text
Псевдоссылка открывает попап с пояснением и не меняет страницу.
```

#### Неправильно

```text
Псевдоссылка ведёт на другую страницу.
```

#### Почему

Пользователь воспринимает разные типы ссылок по-разному. Псевдоссылка не должна обещать переход.

### Rule 5: Не используйте ссылки без подчёркивания

- ruleId: rule:components.link.no-underline-exception
- severity: error
- appliesTo: component
- checkType: deterministic
- autofix: partial

Ссылки без подчёркивания не используются. Исключение — кликабельный номер телефона: он может выделяться только цветом.

#### Правильно

```text
8 800 100 77 33
```

#### Неправильно

```text
Справка по тарифам
```

#### Почему

Текст без подчёркивания может выглядеть как обычный текст, особенно для пользователей, которые плохо различают цвета.

### Rule 6: Выбирайте цвет ссылки по контексту

- ruleId: rule:components.link.context-color
- severity: error
- appliesTo: component
- checkType: llm
- autofix: no

Используйте только предусмотренные цвета: синий `text/info`, чёрный `text/primary`, серый `text-secondary` или белый `text_Inverted/primary`. Не окрашивайте ссылки в другие цвета без согласования с дизайн-системой.

#### Правильно

```text
Синяя ссылка на белом фоне.
```

#### Неправильно

```text
Красная ссылка для привлечения внимания.
```

#### Почему

Нестандартный цвет ломает визуальную систему и может конфликтовать со статусными цветами.

### Rule 7: В карточках не заменяйте стандартные действия ссылками

- ruleId: rule:components.link.cards-actions
- severity: warning
- appliesTo: component
- checkType: llm
- autofix: no

В карточках можно использовать синие вспомогательные ссылки и псевдоссылки. В `TitleView` используйте `RightAddon` и `Type :: Link`. Для стандартных и понятных действий используйте `IconButton` или текстовую кнопку, а не ссылку.

#### Правильно

```text
В карточке действие «Добавить адрес» оформлено как кнопка View :: Text.
```

#### Неправильно

```text
В карточке действие «Добавить адрес» оформлено как обычная ссылка.
```

#### Почему

Кнопка лучше считывается как действие с объектом, а ссылка — как переход или дополнительная справочная возможность.

### Rule 8: Соблюдайте правила для компонентов

- ruleId: rule:components.link.component-context
- severity: warning
- appliesTo: component
- checkType: llm
- autofix: no

В `Plate`, островах, `Hint`, `Tooltip`, `Notification` и FAQ ссылки оформляются по контексту компонента. Не переносите общий синий стиль ссылки туда, где компонент требует наследовать цвет текста или использовать кнопку.

#### Правильно

```text
Ссылка внутри Caption в Notification наследует цвет текста и подчёркнута.
```

#### Неправильно

```text
Ссылка внутри Notification окрашена в синий цвет.
```

#### Почему

Компоненты имеют собственные визуальные правила, чтобы сохранять контраст, иерархию и читаемость.

### Rule 9: Оформляйте ссылки в Tooltip синим цветом и подчёркиванием

- ruleId: rule:components.link.tooltip
- severity: warning
- appliesTo: component
- checkType: deterministic
- autofix: partial

Ссылка внутри Tooltip синяя, подчёркнутая и того же размера, что и текст Tooltip. Внешние ссылки в Tooltip не помечаются диагональной стрелкой.

#### Правильно

```text
В Tooltip внешняя ссылка выделена цветом и подчёркиванием без стрелки.
```

#### Неправильно

```text
В Tooltip внешняя ссылка дополнена диагональной стрелкой.
```

#### Почему

Tooltip — компактный компонент. Иконка стрелки создаёт лишний визуальный шум.

### Rule 10: Legal-ссылки делайте серыми

- ruleId: rule:components.link.legal
- severity: warning
- appliesTo: component
- checkType: deterministic
- autofix: partial

В legal-тексте используйте серые ссылки `text-secondary`, подчёркивание и тот же размер, что у соседнего текста. В чекбоксах ссылки тоже серые и подчёркнутые.

#### Правильно

```text
Ссылка на лицензию в legal-тексте серая и подчёркнутая.
```

#### Неправильно

```text
Ссылка на лицензию в legal-тексте синяя.
```

#### Почему

Legal-ссылки должны быть доступны, но не конкурировать с основными действиями экрана.

### Rule 11: Помечайте standalone-внешние ссылки диагональной стрелкой

- ruleId: rule:components.link.external-standalone
- severity: error
- appliesTo: component
- checkType: deterministic
- autofix: partial

Отдельная внешняя ссылка получает `RightAddon` с иконкой `arrow-right-up-compact` и открывается в новой вкладке браузера. Для кнопки, которая открывает новое окно, используйте `RightAddon` с иконкой `arrow-right-up`.

#### Правильно

```text
Открыть сайт ФНС ↗
```

#### Неправильно

```text
Открыть сайт ФНС
```

#### Почему

Пользователь должен понимать, что покинет текущий сценарий или откроет отдельную вкладку.

### Rule 12: Не помечайте встроенные внешние ссылки стрелкой

- ruleId: rule:components.link.external-inline
- severity: warning
- appliesTo: text
- checkType: deterministic
- autofix: partial

Внешняя ссылка внутри основного текста оформляется как обычная текстовая ссылка: цветом и подчёркиванием, без диагональной стрелки.

#### Правильно

```text
Подробнее читайте на сайте ФНС.
```

#### Неправильно

```text
Подробнее читайте на сайте ФНС ↗.
```

#### Почему

В тексте стрелка утяжеляет строку и мешает чтению.

### Rule 13: Пишите самодостаточный текст ссылки

- ruleId: rule:components.link.self-contained-text
- severity: error
- appliesTo: text
- checkType: dictionary
- autofix: partial

Текст ссылки должен объяснять цель перехода или действия. Не используйте слова «здесь», «тута», «документ», «файл», «ссылка», «сайт» как единственный текст ссылки.

#### Правильно

```text
Посмотреть условия тарифа
```

#### Неправильно

```text
Посмотреть здесь
```

#### Почему

Пользователь сканирует ссылки отдельно от текста. Непонятная ссылка не помогает выбрать действие.

### Rule 14: Не включайте лишнюю пунктуацию в ссылку

- ruleId: rule:components.link.punctuation
- severity: warning
- appliesTo: text
- checkType: llm
- autofix: partial

Не включайте в ссылку знаки препинания и союзы, если они только разделяют ссылки или обычный текст и ссылку. Включайте предлоги и пунктуацию, если без них ссылка теряет смысл.

#### Правильно

```text
Перейдите в раздел «Настройки компании».
```

#### Неправильно

```text
Перейдите в раздел «Настройки компании.»
```

#### Почему

Лишняя пунктуация увеличивает кликабельную область и визуально смешивает ссылку с обычным текстом.

### Rule 15: Пишите адрес сайта без протокола и www

- ruleId: rule:components.link.url-format
- severity: warning
- appliesTo: text
- checkType: deterministic
- autofix: partial

Адрес сайта пишите без `https://` и `www`. Если адрес не помещается в строку, переносите его целиком на следующую строку, а не разрывайте внутри.

#### Правильно

```text
alfabank.ru/make-money/deposits/alfa/
```

#### Неправильно

```text
https://www.alfabank.ru/
```

#### Почему

Короткий адрес легче прочитать и перепроверить. Разорванный URL хуже считывается и может выглядеть ошибочным.

## Section 7: Шаблоны

### Обычная ссылка

```text
[Информативный текст ссылки]
```

Используйте для перехода внутри продукта или на внешний ресурс. В тексте ссылка подчёркнута, окрашена по контексту и имеет тот же размер, что и соседний текст.

### Псевдоссылка

```text
[Текст действия или пояснения]
```

Используйте для открытия попапа, модального окна, дропдауна, коллапса или запуска действия на текущей странице. В спецификации для разработки укажите, что это псевдоссылка.

### Standalone-внешняя ссылка

```text
[Текст ссылки] + arrow-right-up-compact
```

Используйте для отдельной ссылки на внешний ресурс. Такая ссылка открывается в новой вкладке.

### Внешняя ссылка внутри текста

```text
Текст до ссылки [информативный текст ссылки] текст после ссылки.
```

Не добавляйте диагональную стрелку к внешней ссылке, если она встроена в строку основного текста.

### Legal-ссылка

```text
[Текст legal-ссылки]
```

Используйте серый цвет `text-secondary`, подчёркивание и размер соседнего legal-текста.

## Section 8: Примеры

### Пример 1: Обычная ссылка в тексте

```text
Подробнее об условиях тарифа
```

Ссылка объясняет, куда попадёт пользователь, и не требует дополнительного контекста.

### Пример 2: Псевдоссылка

```text
Как считается лимит
```

Псевдоссылка открывает информационный слой с пояснением и не переводит пользователя на другую страницу.

### Пример 3: Legal-ссылка

```text
Условия обработки персональных данных
```

В legal-тексте ссылка серая, подчёркнутая и того же размера, что и основной legal-текст.

### Пример 4: Внешняя ссылка

```text
Открыть сайт ФНС ↗
```

Отдельная внешняя ссылка помечена диагональной стрелкой и открывается в новой вкладке.

### Пример 5: Адрес сайта

```text
Узнайте больше про Альфа-Вклад:
alfabank.ru/make-money/deposits/alfa/
```

URL перенесён целиком и написан без `https://` и `www`.

## Section 9: Антипримеры

### Антипример 1: Непонятный текст ссылки

```text
Подробнее здесь
```

Слово «здесь» не объясняет, куда ведёт ссылка.

### Антипример 2: Ссылка без подчёркивания

```text
Справка по валютному контролю
```

Если ссылка отличается только цветом, часть пользователей может не распознать её как интерактивный элемент.

### Антипример 3: Внешняя standalone-ссылка без стрелки

```text
Открыть сайт ФНС
```

Пользователь не видит, что ссылка ведёт во внешний ресурс.

### Антипример 4: Ссылка вместо кнопки в карточке

```text
Добавить адрес
```

Если действие изменяет объект карточки, используйте кнопку `View :: Text`, а не ссылку.

### Антипример 5: Разорванный URL

```text
Узнайте больше про Альфа-Вклад: alfabank.ru/
make-money/deposits/alfa/
```

URL нельзя разрывать внутри строки. Переносите адрес целиком.

## Section 10: Машинная обработка

### Детерминированные проверки

- Проверять, что `platforms` содержит только `desktop`.
- Проверять наличие `figmaLink` в метаданных.
- Проверять, что standalone-внешняя ссылка использует иконку `arrow-right-up-compact`.
- Проверять, что кнопка, открывающая новое окно, использует иконку `arrow-right-up`.
- Проверять, что в URL нет `https://` и `www`, если адрес показан пользователю как текст.
- Проверять, что legal-ссылки используют `text-secondary`.
- Проверять, что ссылка внутри Tooltip не содержит диагональную стрелку.

### Словарные проверки

- Находить ссылки с текстом «здесь», «тута», «документ», «файл», «ссылка», «сайт».
- Находить формулировки, где ссылка не объясняет цель перехода.
- Находить адреса сайтов с `https://` или `www`.

### LLM-проверки

- Проверять, что Link не используется вместо основного CTA.
- Проверять, что псевдоссылка не обещает переход на другую страницу.
- Проверять, что оформление ссылки соответствует контексту компонента.
- Проверять, что текст ссылки самодостаточен без соседнего текста.
- Проверять, что пунктуация и союзы включены в ссылку только когда они нужны по смыслу.
- Проверять, что в карточке ссылка не заменяет стандартное действие с объектом.

### Не проверяется автоматически

- Фактическая работоспособность ссылки.
- Соответствие ссылки целевой странице или документу.
