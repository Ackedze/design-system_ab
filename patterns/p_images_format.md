## Section 1: Определение

Паттерн описывает, какие изображения используются в интерфейсах, в каких размерах их готовить, где применять и какие требования соблюдать при экспорте, кадрировании и работе с охранными зонами.

Изображения используются в Альфа-Бизнесе, АБМ, Mobile Web и мобильном адаптиве. Независимо от размера, изображение должно занимать максимально возможное пространство, не заходя на охранные поля.

## Section 2: Когда использовать

Используйте паттерн при подготовке:

- заглавных изображений посадочных страниц;
- вспомогательных изображений для лендингов;
- рекламных баннеров и плейсментов;
- навигационных карточек;
- элементов выбора;
- блоков с шагами;
- пиктограмм продукта и изображений для `IconView`;
- списков преимуществ и компактных карточек.

## Section 3: Когда не использовать

Не используйте паттерн для иконок интерфейса, логотипов в брендовых библиотеках, фотографий без прозрачного фона и изображений, которые не должны работать как квадратный PNG-ассет.

Не используйте размер `XS` для изображений, которые требуют обрезки: компактный размер не выдерживает кадрирование без потери смысла.

## Section 4: Принципы

1. Изображение всегда квадратное, с соотношением сторон `1 x 1`.
2. Фон изображения прозрачный.
3. Формат экспорта — `PNG`.
4. Для Альфа-Бизнеса нужна версия `x2`, для Mobile Web, АБМ и мобильного адаптива — `x3`.
5. Изображение должно работать на белой, серой и комплементарной подложке.
6. Важные детали не должны заходить на охранные зоны или попадать в область допустимой обрезки.

## Section 5: Структура текста

В описании изображения фиксируйте размер, назначение, экспортные масштабы, подложки, охранные зоны и допустимое кадрирование.

Для размера `S` отдельно указывайте вариант изображения: центрированный или прижатый к нижнему краю. Для цветной подложки передавайте комплементарный цвет.

## Section 6: Правила

### Rule 1: Делай изображение квадратным

- ruleId: rule:media.images-and-formats.square-ratio
- severity: error
- appliesTo: component
- checkType: deterministic
- autofix: no

Все изображения в паттерне должны иметь соотношение сторон `1 x 1`.

#### Правильно

```text
534 x 534 px
```

#### Неправильно

```text
534 x 420 px
```

#### Почему

Единый квадратный формат упрощает адаптацию изображения на разных платформах и подложках.

### Rule 2: Используй прозрачный PNG

- ruleId: rule:media.images-and-formats.transparent-png
- severity: error
- appliesTo: component
- checkType: deterministic
- autofix: no

Изображение должно экспортироваться в `PNG` с прозрачным фоном.

#### Правильно

```text
PNG с alpha channel
```

#### Неправильно

```text
PNG с белым фоном внутри ассета
```

#### Почему

Прозрачный фон позволяет использовать изображение на белой, серой и цветной подложке.

### Rule 3: Готовь версии x2 и x3

- ruleId: rule:media.images-and-formats.export-scales
- severity: error
- appliesTo: component
- checkType: deterministic
- autofix: no

Для Альфа-Бизнеса нужна версия `x2`, для Mobile Web, АБМ и мобильного адаптива — версия `x3`.

#### Правильно

```text
image@2x.png
image@3x.png
```

#### Неправильно

```text
Передан только image@2x.png
```

#### Почему

Разные платформы требуют разные масштабы, чтобы изображение оставалось чётким.

### Rule 4: Используй размер M для заглавных блоков

- ruleId: rule:media.images-and-formats.size-m
- severity: warning
- appliesTo: component
- checkType: deterministic
- autofix: no

Размер `M` — `534 x 534 px`. Он используется в заглавных блоках посадочных страниц и для главной метафоры.

#### Правильно

```text
M: 534 x 534 px для hero-блока лендинга
```

#### Неправильно

```text
XS: 80 x 80 px для главной метафоры лендинга
```

#### Почему

Главная метафора должна занимать крупную визуальную область.

### Rule 5: Используй размер S для вспомогательных и рекламных изображений

- ruleId: rule:media.images-and-formats.size-s
- severity: warning
- appliesTo: component
- checkType: deterministic
- autofix: no

Размер `S` — `348 x 348 px`. Он используется во вспомогательных блоках лендингов, рекламных баннерах, навигационных карточках, элементах выбора и блоках с шагами.

#### Правильно

```text
S: 348 x 348 px для навигационной карточки
```

#### Неправильно

```text
M: 534 x 534 px для компактной навигационной карточки
```

#### Почему

Размер `S` сохраняет видимость изображения, но не перегружает второстепенные блоки.

### Rule 6: Используй размер XS для пиктограмм и компактных размещений

- ruleId: rule:media.images-and-formats.size-xs
- severity: warning
- appliesTo: component
- checkType: deterministic
- autofix: no

Размер `XS` — `80 x 80 px`. Он используется в рекламных плейсментах, карточках, списках преимуществ, пиктограммах продукта и `IconView`.

#### Правильно

```text
XS: 80 x 80 px для IconView
```

#### Неправильно

```text
XS с обрезкой значимой детали
```

#### Почему

Компактные изображения должны оставаться целыми: обрезка в `XS` быстро разрушает смысл.

### Rule 7: Соблюдай охранные зоны размера M

- ruleId: rule:media.images-and-formats.safe-area-m
- severity: error
- appliesTo: component
- checkType: manual
- autofix: no

Для размера `M` охранные зоны: `10%` сверху и снизу, `5%` слева и справа.

#### Правильно

```text
M: значимые детали не заходят в 10% сверху и снизу, 5% слева и справа.
```

#### Неправильно

```text
M: важная деталь стоит вплотную к верхнему краю.
```

#### Почему

Охранные зоны защищают изображение от конфликтов с краями контейнера и кадрированием.

### Rule 8: Соблюдай охранные зоны размера S

- ruleId: rule:media.images-and-formats.safe-area-s
- severity: error
- appliesTo: component
- checkType: manual
- autofix: no

Для центрированного `S` используйте `10%` сверху и снизу, `5%` слева и справа. Для варианта, прижатого к нижнему краю, снизу отступ не используется.

#### Правильно

```text
S centered: 10% сверху и снизу, 5% слева и справа.
S bottom: 10% сверху, 5% слева и справа, снизу без отступа.
```

#### Неправильно

```text
S bottom: значимая деталь выходит за правую охранную зону.
```

#### Почему

У размера `S` есть два разных сценария композиции, и для них нужны разные нижние отступы.

### Rule 9: Соблюдай охранные зоны размера XS

- ruleId: rule:media.images-and-formats.safe-area-xs
- severity: error
- appliesTo: component
- checkType: manual
- autofix: no

Для размера `XS` охранные зоны составляют `15%` со всех сторон. Для версии, прижатой к нижнему краю, снизу отступ не используется.

#### Правильно

```text
XS: значимые детали внутри зоны с отступами 15%.
```

#### Неправильно

```text
XS: значимая деталь находится на самом краю изображения.
```

#### Почему

На маленьком размере даже небольшой заход в край делает изображение шумным и нечитаемым.

### Rule 10: Учитывай допустимое кадрирование

- ruleId: rule:media.images-and-formats.crop-limits
- severity: error
- appliesTo: component
- checkType: manual
- autofix: no

Для `M` допустима нижняя обрезка до `20%` в Альфа-Бизнесе и до `30%` в MW / АБМ. Для центрированного `S` допустима обрезка справа до `10%` и снизу до `20%`. Для `S`, прижатого к низу, допустима обрезка справа до `10%`, но снизу обрезки быть не должно. `XS` используется без обрезки.

#### Правильно

```text
S centered: crop right <= 10%, crop bottom <= 20%.
```

#### Неправильно

```text
XS: crop bottom 10%.
```

#### Почему

Допустимое кадрирование зависит от размера и композиции изображения.

### Rule 11: Проверяй изображение на трёх подложках

- ruleId: rule:media.images-and-formats.substrate-check
- severity: warning
- appliesTo: component
- checkType: manual
- autofix: no

Перед передачей изображение нужно примерить на белой `#FFFFFF`, серой `#F2F3F5` и цветной комплементарной подложке.

#### Правильно

```text
Проверены белая, серая и комплементарная подложки.
```

#### Неправильно

```text
Изображение проверено только на белом фоне.
```

#### Почему

На разных подложках могут проявиться проблемы с контрастом, краями и прозрачностью.

## Section 7: Шаблоны

### Размер M

```text
Размер: 534 x 534 px
Формат: PNG
Фон: прозрачный
Экспорт: x2 для АБ, x3 для MW / АБМ / mobile adaptive
Охранные зоны: 10% сверху и снизу, 5% слева и справа
Кадрирование: снизу до 20% в АБ, до 30% в MW / АБМ
```

### Размер S

```text
Размер: 348 x 348 px
Варианты: центрированный, прижатый к нижнему краю
Формат: PNG
Фон: прозрачный
Экспорт: x2 для АБ, x3 для MW / АБМ / mobile adaptive
```

### Размер XS

```text
Размер: 80 x 80 px
Формат: PNG
Фон: прозрачный
Охранные зоны: 15% со всех сторон
Кадрирование: без обрезки
```

### Передача изображения

```text
Исходное квадратное изображение
PNG с прозрачным фоном
Версии x2 и x3
Комплементарный цвет подложки, если нужен
Проверка на белой, серой и цветной подложке
```

## Section 8: Примеры

### Пример 1: Hero-изображение

```text
M, 534 x 534 px, PNG, прозрачный фон, x2 и x3
```

Размер подходит для заглавного блока посадочной страницы.

### Пример 2: Навигационная карточка

```text
S, 348 x 348 px, центрированная версия и версия, прижатая к нижнему краю
```

Размер подходит для вспомогательного сценария и рекламного размещения.

### Пример 3: IconView

```text
XS, 80 x 80 px, без обрезки
```

Компактная пиктограмма должна оставаться целой.

### Пример 4: Проверка подложек

```text
#FFFFFF
#F2F3F5
Комплементарная подложка
```

Изображение должно корректно выглядеть на всех трёх типах фона.

## Section 9: Антипримеры

### Антипример 1: Неквадратное изображение

```text
534 x 420 px
```

Формат нарушает соотношение `1 x 1`.

### Антипример 2: Непрозрачный фон

```text
PNG с белым прямоугольником внутри ассета
```

Такое изображение плохо работает на серой и цветной подложке.

### Антипример 3: Один масштаб

```text
Передан только x2.
```

Для Mobile Web, АБМ и мобильного адаптива нужна версия `x3`.

### Антипример 4: XS с обрезкой

```text
XS, crop bottom 10%
```

Размер `XS` используется без обрезки.

### Антипример 5: Нет проверки на подложках

```text
Проверено только на белом фоне.
```

Изображение может потеряться на серой или цветной подложке.

## Section 10: Машинная обработка

### Детерминированные проверки

- Проверять формат файла `PNG`.
- Проверять наличие alpha channel.
- Проверять соотношение сторон `width = height`.
- Проверять базовые размеры `M = 534 x 534 px`, `S = 348 x 348 px`, `XS = 80 x 80 px`.
- Проверять наличие версий `x2` и `x3`.
- Проверять, что `XS` не используется с обрезкой.

### Словарные проверки

- Определять сценарии для размеров `M`, `S` и `XS` по словам: hero, лендинг, баннер, карточка, IconView, пиктограмма, преимущества.
- Находить упоминания белой, серой и комплементарной подложки в описании передачи.
- Находить отсутствие формата `PNG`, прозрачного фона или экспортных масштабов.

### LLM-проверки

- Проверять, что выбранный размер соответствует месту использования.
- Проверять, что значимые детали не попадают в охранные зоны и область кадрирования.
- Проверять, что изображение занимает максимально возможное пространство без нарушения охранных полей.
- Проверять, что для размера `S` выбран нужный вариант композиции.

### Не проверяется автоматически

- Визуальное качество иллюстрации.
- Корректность комплементарного цвета.
- Фактическая читаемость деталей на разных подложках.
- Художественная уместность метафоры.
- Проверка охранных зон без доступа к визуальному анализу ассета.

### Автоисправления

- Переименовать размер в описании, если фактический размер однозначно соответствует `M`, `S` или `XS`.
- Добавить требование `PNG`, если в карточке передачи указан другой текстовый формат без ассета.
- Добавить напоминание про версии `x2` и `x3`.
- Добавить чек-лист проверки на белой, серой и комплементарной подложке.
