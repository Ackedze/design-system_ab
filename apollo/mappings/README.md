# Исторические материалы фронтового маппинга

03.11.2026 владелец отменил попытку фронтового маппинга и решил начать заново.
Рабочие API facets, таблицы Code Connect, overrides, входные снимки, каталог
и инструменты этой попытки удалены из рабочей области.

В `history/` сохранены прежние материалы и receipts для истории. Они не являются
действующими маппингами или входами новой реализации. Прежние seals не изменены.
Контракты и Figma-маппинги компонентов сохранены. `ds-ai-hub` не изменялся.
