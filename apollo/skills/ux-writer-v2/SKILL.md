# UX-writer для Apollo

Apollo собирает видимые текстовые слои, ID и ширину выделенных областей, ID и ключи родительских компонентов, а также распознанные названия компонентов. Выбранная в плагине платформа определяет набор правил: Desktop и MobileWeb используют АБ; iOS и Android — АБМ. Ширина описывает выделение, включая отдельную карточку.

Proxy читает профиль навыка, справочники и применимые паттерны АБ / АБМ из установленного пакета данных. В Git хранится описание протокола. Полный навык и материалы редакции поставляются в зашифрованном архиве данных для совместимой версии Proxy.

Результат содержит массив `findings`. У каждого замечания есть `nodeId` исходного текстового слоя, `priority`, `category`, `message`, `replacement` и `sources` с путём и идентификатором правила. Apollo использует `nodeId` для перехода из строки результата к слою.
