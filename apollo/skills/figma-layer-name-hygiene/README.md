# Переназвать слои

Пакет объединяет основные правила и инструкцию агентского цикла Apollo.
Исполнитель `apollo.layer-names` остаётся установленным кодом Apollo/Proxy.
Процесс выпуска описан в [README каталога](../README.md).

При переносе четыре файла SKILL.md/profile.json сохраняются байт в байт:
основной профиль 0.1.0, профиль цикла 0.2.0. Пакет имеет собственную версию 0.2.0.
Пути внутри прежних профилей обозначают delivery/protocol pins и намеренно
не переписываются под новое расположение исходников.

| Исходник | Путь в пакете данных |
| --- | --- |
| `SKILL.md` | `skills/figma-layer-name-hygiene/SKILL.md` |
| `profile.json` | `skills/figma-layer-name-hygiene/profile.json` |
| `run/SKILL.md` | `skills/figma-layer-name-hygiene-run/SKILL.md` |
| `run/profile.json` | `skills/figma-layer-name-hygiene-run/profile.json` |

Навык предлагает план переименований и сохраняет текст интерфейса, структуру,
оформление и компонентные связи. Ограничения области и защищённых библиотечных
вложенностей остаются в существующем native-исполнителе; инструкция не выдаёт
агенту прямую запись или новые инструменты.
