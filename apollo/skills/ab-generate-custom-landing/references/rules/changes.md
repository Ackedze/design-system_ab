# Изменения существующего макета

Читай при правке или продолжении ранее начатого лендинга. Дополнительно читай
правила только затронутого решения: [композиция](brief-and-composition.md),
[выбор компонента](component-selection.md) или [наполнение](content-and-assets.md).
Для Proxy границы editSectionIds и возобновление — [адаптер](../proxy.md#источники-ограничения-и-продолжение).

По запросу пользователя найди целевую секцию в сохранённой `spec.json` и
фактическом дереве. Перед изменением прочитай её текущий public API и нужные
нормы. Предложение, не поддерживаемое компонентом, требует другого разрешённого
системного варианта или вопроса; не обходи ограничение detach/ручной геометрией.
Меняй только порученный блок и необходимые связанные подписи; сравни before/
after и проверь соседние bounds. Обнови spec, readback, скриншот и отчёт;
полная пересборка страницы не требуется. Параметры принятого брифа сохраняются.

При изменении структуры соблюдай согласование её новой версии по
[порядку работы](../../SKILL.md#порядок-работы). При прерывании сначала прочитай
фактический результат и rollback receipt инструмента; не создавай root заново
и не повторяй запись вслепую. Подтверждённые блоки, история и активный этап сохраняются.
