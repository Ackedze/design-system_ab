# Таблица готовности

Обновляй таблицу только по явному запросу владельца после проверки документов.

Источник:

`https://docs.google.com/spreadsheets/d/1u3Y7lhO3udXAhGlf7hOk2_zYkWZ0-vgtd6KjtbnxLnk/edit#gid=0`

Вкладка для web-corp: `Corp components`.

## Порядок действий

1. Найди строку по точному имени компонента; не используй запомнённый номер строки.
2. Прочитай заголовки, текущие значения, formulas, dropdown validation и форматирование.
3. Сопоставь существующие package files с колонками таблицы.
4. Для каждого документа установи только подтверждённый статус `Ready`, `Draft` или `Legacy`.
5. Общий статус установи в `Ready`, только если обязательные документы готовы и runtime-тест пройден; иначе `In progress`.
6. Сохрани dropdown, conditional formatting, formulas и структуру листа.
7. Перечитай изменённую строку и перечисли пользователю записанные статусы.

Не создавай новые статусы и не отмечай отсутствующий документ `Ready`. Не меняй другие строки при обновлении одного компонента.
